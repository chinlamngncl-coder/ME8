## Concept (yes — this is it)

| Wrong | Right |
|-------|--------|
| Hide **every** grey line everywhere | Blind austerity — Settings/dangerous actions become unexplained |
| Keep a teach essay on **every** page | What you hated (Holds / Retention / “don’t open the folder”) |
| Make **you** pick 70 keys | Operator is not the copy desk |

**Enterprise pattern:**

1. **Working page + clear title** (Cases, Retention, Holds, Groups list) → **no** permanent teach strip. Title + toolbar + data.  
2. **Rare / high-risk / IT config** (SSL, reverse proxy, FTP credentials, first-time wizard) → **one short factual line** next to the control is OK (industry). Not a lecture. Not casual.  
3. **Empty / error / confirm / modal gate** → short guidance OK.  
4. **Manuals** → full teaching.

Agent **decides** which bucket. You **hard-refresh and PASS/FAIL** what you see. You do not maintain the key list.

## Three buckets (agent applies)

| Bucket | When | Action |
|--------|------|--------|
| **A — REMOVE** | Title already names the job; line only restates or coaches (“no need to…”, “categories control…”) | `hidden` + clear string |
| **B — INDUSTRY ONE-LINER** | Operator/IT would misconfigure without a calm fact beside the control | Keep visible; ≤1 short sentence; professional |
| **C — KEEP AS-IS** | Empty state, live status, modal password/PIN step, dock once-wizard, monitor identity labels | Leave |
