## Plain answer

### 1) “Root or sudo” — what does that mean?

**Common IT words:**

| Phrase in guide (Linux) | Plain meaning |
|-------------------------|---------------|
| **Administrator rights** (preferred customer wording) | Permission to install system services and change firewall on that server |
| **root** | The highest-level Linux account (like Windows local Administrator) |
| **sudo** | “Run this one command as administrator” — normal Linux practice |

**Not:** “Only if they want a firewall, then they need root.”

**Correct meaning:**

On **Linux**, installing a **system service** and opening **firewall ports** both need administrator privileges. Same idea as Windows **Run as administrator**.

| Task | Windows | Linux |
|------|---------|--------|
| Install Mobility Axiom as a service | Local **Administrator** / elevated PowerShell | **root** or **sudo** |
| Open firewall ports for the product | Same elevated rights | Same elevated rights |

**Recommended customer wording (next manual tweak):**

> On Linux, sign in with an account that can install services and change the firewall (administrator privileges — often called root or sudo).  
> On Windows, use a local Administrator account (Run as administrator).

Avoid leaving only the short line “Root or sudo rights are required…” without that explanation.

### 2) “Upload license.lic” — upload to where?

**Product design today (code truth):**

License is installed during **Setup Mode** on the **server Setup page** (first-start / license lock screen), **not** on the normal dashboard login UI.

| Step | Where |
|------|--------|
| Open Setup | On the **server**: `http://127.0.0.1:13988` (default) |
| Enter Setup PIN | From the service log |
| Choose file | Setup page control: **Upload / Install license** for `license.lic` |
| File is stored | Server disk: **`storage/license.lic`** under the Mobility Axiom install folder |

So: **yes — there is already a place to upload on the startup Setup page.** That is intentional.

```
Ubitron emails/sends license.lic
        ↓
IT opens Setup on the server (localhost)
        ↓
IT selects the file → Install license
        ↓
Saved as storage/license.lic
        ↓
Service restart → full product boots
```

**Not** “upload into the daily Operations dashboard.”  
**Not** “upload to a random cloud folder.”  
**Not** typing a short activation code in this version — it is a **file**.

**Also valid (same end result):**

- Ubitron / installer places `license.lic` into `storage\license.lic` on disk before start (common when license is pre-issued for a known Hardware ID).  
- Recovery / CLI paths exist for support — not the normal new-client story in the Installation Guide.

**If product design later changes** (e.g. no browser upload, folder-drop only), that needs a **named product MOB** first. Manuals must not invent a different path.

**Recommended customer wording:**

> On the Setup page, use **Install license** and select the `license.lic` file you received from Ubitron.  
> The file is saved on the server (install folder → `storage` → `license.lic`).  
> Do not edit this file.
