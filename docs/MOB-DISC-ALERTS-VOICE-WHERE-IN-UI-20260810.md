# MOB DISC — Where is Alerts & voice (2026-08-10)

**Status:** Nav fact only. No code.

## Operator path

1. Open **Settings** (gear / Server setup).  
2. Left / top tab: **Dashboard Authentication**.  
3. Sub-tab: **Site security**.  
4. Scroll past Site security / Tech PIN / SMTP — section title **Alerts & voice**, then **Alert tones**.

DOM: `#ss-voice-alerts-section` inside `#ss-panel-dashboard`. Shown only when `Site security` is active and the user can manage the server (`canManageServer`).

Not a separate Settings sidebar item named “Alerts & voice”.
