## Four words — what each is

| Name | One sentence |
|------|----------------|
| **SOS** | Alarm: someone pressed help (or fall). |
| **Case** | The **incident folder** for that SOS (and Face/Plate/Weapon too). Desk works here. |
| **Case File** | A **written report** someone fills in — optional, not every SOS. |
| **Redact** | Paint over / mute sensitive bits on a **video** → safe copy. Needs **license** or button is **grey**. You still use Evidence without buying redact. |

**Redacted Exports** = list of safe copies after Redact. Not a fourth kind of case.

---

## What is NOT true

- Case File is **not** required before you can Ack a SOS.  
- Redact is **not** “the case.”  
- FTP is **where video files sit** (path you set) — Case is the **ticket**; Redact makes a **copy**; Redacted Exports **lists** those copies.  
- Browser refresh should **not** erase Cases on disk. Empty after refresh = bug, not design.
